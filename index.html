PTA向けツール集

このリポジトリで公開・管理している PTA 向けのツール一覧です。 スマホでも使えるものから、GitHub Pages 以外で動かしているものまで、ここから入口をまとめています。

TOOL 01

人数カウント

学年と組ごとの人数を入力し、学年別と全体集計をその場で確認できます。

/class-ninzuu-count/
 TOOL 02

みちびき次年度メールジェネレーター

既存の掲載内容をもとに、次年度向けの案内文を作るための補助ツールです。

/michibiki_generator/
 TOOL 03

席次表アプリ

Vite で構成した席次表アプリです。GitHub Pages 公開用にビルドした画面へ移動します。

/seat-app/
 TOOL 04

PTA資料プライベートビューア

PDF を管理画面から登録し、PIN 認証つきでスマホ閲覧できるツールです。 実行環境は Vercel、ソースコードはこの repo の pta-private-viewer/ にあります。

Vercel: ku-pta-private-viewer.vercel.app
GitHub Pages と外部ホスティングの入口をまとめています。
