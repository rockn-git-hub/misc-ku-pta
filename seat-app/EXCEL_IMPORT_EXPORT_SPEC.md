# 席次アプリ Excelインポート・エクスポート仕様案

## この資料の位置付け

- 作成日: 2026-10-10
- 対象: 座席配置、着席情報、Excel・JSONによる保存と復元、ファイル操作UI
- 状態: 利用者と合意した方向性の整理。実装前の未決定事項を含む
- この資料の作成は、アプリの実装変更を意味しない
- 「合意した仕様」は実装の基準。「未決定事項」は実装前に判断・確認する項目

## 1. 目的

会場レイアウトと、誰がどの席に座るかを分けて扱う。
利用者はアプリ上で机を配置し、Excelで着席名簿を編集できる。
Excelから既存の机への着席情報の反映と、会場全体の復元の両方を行える。
JSONも、全体を保存・復元する形式として維持する。

一般の利用者に座標の入力を求めない。
配置情報を理解している利用者は、Excelでテーブルの配置変更・追加・削除も行える。

## 2. 合意した仕様

### 2.1 管理する情報

| 情報 | 内容 |
| --- | --- |
| 会場レイアウト | テーブル名・座標・形状・デザイン・寸法・向き・予定席数 |
| 着席情報 | テーブル名・席番号・氏名・属性1・属性2・参加ON／OFF |

テーブル名で会場レイアウトと着席情報を対応付ける。
利用者に内部IDや内部連番を指定させない。
画面のテーブル名とExcelのテーブル名を対応させ、名前中の数字を内部番号として解釈しない。
同じ会場内のテーブル名は重複させない。

これは利用者から見た情報の分離を定めるもので、内部データ構造の分割方法は未決定。

### 2.2 Excelのシート構成

全体保存用のExcelは、次の2シートとする。

| シート名 | 役割 |
| --- | --- |
| 着席名簿 | 各テーブルの各席に誰が座るかを編集・保存する |
| 会場レイアウト | テーブル配置の復元に必要な情報を保存する |

着席名簿だけ取り込む場合は、「着席名簿」1シートだけのExcelも受け付ける。
全体復元には両シートを使う。

### 2.3 着席名簿シート

1行につき1席を記載する。
エクスポートでは、空席を含めて表示対象の全席を出力する。

| テーブル名 | 席番号 | 氏名 | 属性1 | 属性2 | 参加 |
| --- | ---: | --- | --- | --- | --- |
| A組の卓 | 1 | 山田 太郎 | A組 | | ON |
| A組の卓 | 2 | | | | |
| A組の卓 | 3 | 鈴木 花子 | A組 | | OFF |
| 先生の卓 | 1 | 佐藤 一郎 | 教諭 | | ON |

- テーブル名と席番号で配置先を指定する
- 席番号は必須で、1以上の整数とする
- 氏名が空欄の行は空席として扱う
- 行を省略した席も空席として扱う
- Excelの行順を変更しても、席番号による配置は変わらない
- 属性1・属性2は任意。今回の参加者では属性1にクラスまたは「教諭」を使う
- 「参加」列で参加者ごとのON／OFFを保存・復元する
- 参加OFFでも氏名・属性・席の割り当てを保存する。画面やPDFで隠すことと、保存データから削除することを区別する
- 「参加」列・項目がない既存のExcel・JSONは全員ONとして扱う
- 属性1・属性2の表示見出しは利用者が変更でき、変更した見出しもExcel・JSONに保存・復元する。列との対応付け方法は未決定
- 行の追加・編集・削除によって着席情報を変更できる
- 同行者も1人ずつ別行にする。氏名不明の場合は仮表示名を使える
- Excelに人数や席数を重複して記入する列は設けない
- 表の途中に見出し、合計行、結合セルを入れない

席番号を省略して行順に配置する方式は採用せず、明示的な席番号を使う。

### 2.4 会場レイアウトシート

テーブル一覧は1行につき1卓とする。

| 項目 | 意味 |
| --- | --- |
| テーブル名 | 着席名簿との対応付けに使う名前 |
| 形状・デザイン | 円卓・正方形・長机・くっつけた長机を復元する情報 |
| 向き | 横・縦を復元する情報 |
| X座標・Y座標 | アプリ上の位置 |
| 幅・高さ・半径 | 形状に応じた寸法 |
| 予定席数 | そのテーブルの基本となる席数 |

列名、単位、形状ごとの必須列、具体的な保存値は未決定。
全体復元に必要な情報を、配置図だけでなく値として保存する。
配置図を併記するかは未決定であり、図を復元の入力データにはしない。

#### 通常の使い方

- 座標・寸法などはアプリが自動出力する
- 利用者はアプリ上で配置を調整してから保存する
- 復元用のセルは薄いグレーで表示し、ロックする
- パスワードなしのシート保護を使う
- 「配置の変更はアプリで行ってください。手動編集する場合はシート保護を解除してください」と案内する

#### 手動編集する場合

- 利用者がシート保護を解除して編集できる
- 既存行をコピーし、テーブル名・位置・形状・席数などを変更してテーブルを追加できる
- 行を削除することで、全体復元時にそのテーブルを除外できる
- 形状・向きは選択式とする
- 数値項目には入力制限を設ける
- 列の意味、単位、入力例をシート内に記載する
- 新しいテーブルへ着席させる場合は、両シートに同じテーブル名を記入する

シート保護は誤編集を防ぐためのものとし、セキュリティ目的には使わない。

### 2.5 席数と空席のルール

着席名簿で指定された席を優先し、予定席数を超える席番号も配置できるようにする。

```text
反映する席数 = max(予定席数, 名簿で指定された最大席番号)
```

最大席番号には、氏名が空欄の明示的な空席行も含む。
指定行がないテーブルは、予定席数を維持して全席空席とする。

| 予定席数 | 名簿の指定 | 結果 |
| ---: | --- | --- |
| 6 | 1・2・3・5・6番に着席 | 6席。4番は空席 |
| 4 | 1・2・3・4・5番に着席 | 5席へ増加 |
| 4 | 1・2・5番に着席 | 5席。3・4番は空席 |
| 6 | 1・2番に着席 | 6席。3〜6番は空席 |
| 4 | 8番を空席として指定 | 8席。指定された空席も席数に反映 |

席数の増加は予定席数そのものを書き換える操作と分ける。
机の位置・形・大きさを維持し、表示する席の並びを再計算する。
氏名枠が重なる可能性は、取り込み前の配置確認で確認できるようにする。

### 2.6 読み込み操作

#### 着席名簿だけ取り込む

- Excelの着席名簿を、現在の会場レイアウトに反映する
- 既存テーブルの表示名と一致するテーブルを探す
- テーブルを自動作成・削除しない
- 机の位置・形・大きさ・名前を維持する
- 席番号の指定に応じて席数を増やす
- 着席情報は全体置き換えとし、以前の着席情報を残さない
- 名簿に登場しないテーブルも残し、着席情報を空にする
- 同じExcelに会場レイアウトがあっても、この操作では配置情報を反映しない
- 取り込みは1操作として履歴に記録し、「元に戻す」で取り込み前へ戻せる

#### 全体を復元

- ExcelまたはJSONから、会場レイアウトと着席情報を復元する
- Excelでは会場レイアウトに記載されたテーブル一覧を基準にする
- テーブルの追加・削除・位置・形・寸法・向き・予定席数を反映する
- 着席名簿を、復元対象のテーブル名と席番号で対応付ける
- 現在の会場データへの追記ではなく、保存データによる全体置き換えとする
- 現在のデータと操作履歴を置き換えることを確認画面に明記する
- 確定するまで現在のデータと履歴を保持し、確定した全体復元後は操作履歴をリセットする

### 2.7 入力検証と確定前の確認

読み込みは、解析・検証・結果確認・確定の順に行う。
確定前に現在のデータを書き換えない。
エラーがある場合は、一部だけ反映せず、全体の反映を止める。

#### エラーとして扱う事項

- 会場レイアウトのテーブル名が重複している
- テーブル名が空欄、または配置先のテーブルが存在しない
- 同じテーブル内の席番号が重複している。空席行との重複も含む
- 席番号が空欄・0以下・小数などになっている
- 座標・寸法・席数・形状などの復元情報が不正

問題のシート名、Excel上の行番号、項目、理由を表示する。
同姓同名だけを理由にエラーにはしない。参加者の識別方法は未決定。

#### 確定前に表示する情報

- 読み込み方法と、現在の配置を置き換えるかどうか
- テーブル数、着席人数、空席数
- 席数が増えるテーブルと増加前後の席数
- 全体復元では、追加・削除されるテーブル
- 入力エラーの一覧
- 取り込み後の配置確認

### 2.8 ファイル操作UI

上部の「ファイル」に操作を集約する。

| メニュー | 内容 |
| --- | --- |
| 全体を保存 | ExcelまたはJSONを選択して保存 |
| 全体を復元 | ExcelまたはJSONから全体を復元 |
| 着席名簿だけ取り込む | Excelから、現在の机配置を保って着席情報を反映 |
| PDF出力 | 氏名・属性の表示設定に従って印刷用の席次表を出力 |
| 新規作成 | 確認後に机・参加者名簿・操作履歴を初期化 |

操作の目的を先に選び、ファイル形式はその後に選ぶ。
参加者画面は名簿の確認・編集を担当し、ファイル操作を重複配置しない。

読み込み画面には次のような説明を表示する。

- 全体を復元: 「机の配置と着席情報を置き換え、操作履歴をリセットします」

### 6.3 編集モード

#### 会場配置

- 卓をクリックして選択し、右側に設定を表示する
- 卓をドラッグして移動する
- 選択した卓のハンドルで大きさを変更する
- 席をクリックしても参加者を入れ替えない
- 氏名・属性の表示は「氏名・属性を表示」のチェックボックスで切り替える
- 右側でテーブル名、形状、向き、予定席数、大きさを扱う
- 座標は通常の編集項目として前面に出さず、「詳細設定」で扱う

#### 着席編集

- 卓の移動・サイズ変更を止める
- 席をクリックし、右側でその席の参加者を確認・変更する
- 氏名・属性は全体の表示設定と参加ON／OFFに従って表示する
- 空席・未着席者を確認できるようにする
- 席の選択だけでは着席情報を変更しない

#### 氏名・属性の表示設定

- 上部のモード切り替え付近に「氏名・属性を表示」のチェックボックスを置く
- 初期状態はチェックありとする
- チェックを外すと氏名・属性を隠し、卓名と席番号を表示する
- 表示の切り替えでは名簿と席の割り当てを変更しない
- 表示設定はExcel・JSONに保存・復元する
- PDFも表示設定に従う。氏名を隠した状態なら、氏名・属性なしで出力する
- 参加OFFの人は、全体の表示設定がONでも画面・PDFの氏名・属性を隠す

### 6.4 卓・席の編集欄

卓名を編集欄の見出しとし、席数と着席人数を表示する。
着席編集では卓内の席番号・氏名・属性を一覧表示し、選択した席を強調する。
画面の席選択と一覧の行選択を連動させる。

選択した席に対して、次の操作を用意する。

- 参加者を変更: 名簿から氏名検索で選ぶ
- 空席にする: その席の割り当てを解除する
- 席を入れ替える: 入れ替え先の選択を開始する

内部IDを一般の利用者向けの編集項目にしない。
長い氏名が会場図で省略されても、編集欄では全文を確認できるようにする。
氏名・属性を編集する操作と、別の参加者を割り当てる操作を区別する。
氏名・属性の編集が参加者名簿にも反映されることを表示する。
属性の見出しは利用者が「クラス」「役職」などに変更できるようにする。
テーブル名を変更しても、同じ卓の着席情報を保持する。Excelには変更後の名前を出力する。
別の卓と同じ名前への変更は止める。

#### 参加者一覧からの割り当てと移動

- 別の席に着席済みの参加者を選ぶと、新しい席へ移動し、元の席を空席にする
- 移動先に別の参加者がいる場合は、確認して置き換え、その人を名簿に残して未着席へ戻す
- 席同士の入れ替えとは別の操作として扱う
- 「空席にする」は割り当てだけを解除し、参加者を名簿に残して未着席へ戻す
- 参加者の「参加」ON／OFFも変更できるようにする

#### 席数・形状の変更

- 席数を減らす際、削除される席に参加者がいれば確認を出す
- 確定後、該当者を未着席へ戻す。参加者名簿と参加ON／OFFは保持する
- 形状変更では席数・席番号・参加者の割り当てを保持し、席の並びを変更する

### 6.5 席の入れ替え

1. 入れ替え元の席を選択する
2. 「席を入れ替える」を押す
3. 元の席を強調し、「入れ替え先を選んでください」と表示する
4. 別の席をクリックして入れ替える

空席との入れ替えにも対応する。
Escまたは「キャンセル」で入れ替え操作を解除する。
単なる席の選択と、入れ替え操作を区別する。
実行後は「元に戻す」で復旧できるようにする。

### 6.6 表示倍率・会場図の移動・検索

表示倍率は会場の座標・寸法と独立させる。
拡大・縮小しただけで机の位置や大きさ、席次データを書き換えない。

| 操作 | 動作 |
| --- | --- |
| 全体表示 | 用紙全体が表示領域に収まる倍率と位置へ調整 |
| ＋／−、倍率表示 | 会場図の表示を拡大・縮小 |
| 選択した卓を表示 | 選択した卓が見える位置へ移動 |
| スクロール | 会場図の表示位置を移動 |
| Spaceを押しながらドラッグ | 机の移動と区別して会場図の表示位置を移動 |
| 検索 | 卓名・参加者名から候補を表示し、選択した卓・席へ移動・強調表示 |

現在の`scale`は用紙領域の幅・高さに影響しているため、表示倍率としてそのまま流用しない。
既存データの`scale`の取り扱いは実装前に確定する。

検索・参加者選択の候補には氏名だけでなく、属性と現在の着席先を表示する。
同姓同名も属性と「卓名・席番号」または「未着席」で区別できるようにする。
参加OFFの人も候補に載せ、「不参加」と表示する。

用紙の縦横変更では、会場全体の中心を基準に卓の位置を90度回転する。
長机は横長と縦長を入れ替え、幅と高さを交換する。円卓・正方形の形と大きさは維持する。
着席情報は同じ卓・同じ席番号に保持し、文字は読みやすい向きで表示する。
縦から横、横から縦へ戻す際の回転方向や計算方法は、往復の整合を保つよう実装側で決める。

### 6.7 卓の追加・複製・削除

「テーブルを追加」から形状を選び、必要な向きと席数を指定する。
追加した卓は現在見えている会場図の中央へ置き、選択状態にする。
卓が重なっても追加・移動を許可する。重なりの警告や自動位置調整は行わない。

複製は「卓を複製」と表示する。
机の位置・形・大きさ・席数などの設定を複製し、参加者はコピーせず全席空席とする。
卓名は会場内で重複させない。
Ctrl+Cは卓の設定をコピーするだけとし、その時点で新しい卓を作らない。
Ctrl+Vでコピーした設定から新しい卓を作る。
会場図上にマウスがある場合は、その位置を新しい卓の中心とする。
会場図の外にマウスがある場合は、見える範囲の中央へ貼り付ける。
貼り付け位置は表示倍率とスクロールを考慮する。

卓の削除は選択中の卓の編集欄から行う。
着席者がいる場合は人数を示して確認し、確定後に卓を削除する。
削除された卓の参加者は名簿に残し、未着席へ戻す。

### 6.8 人数・問題の状態表示

各参加者に「参加」のON／OFFを設け、いつでも切り替えられるようにする。
OFFでも名簿と席の割り当てを保持する。ONに戻すと同じ席で再表示できる。
全体の氏名・属性表示がOFFの場合は、参加ONでも氏名・属性を表示しない。
参加ON／OFFはExcel・JSONに保存・復元する。項目のない既存データは全員ONとする。

下部の人数表示は次の基準とする。

| 項目 | 対象 |
| --- | --- |
| 参加人数 | 参加ONの人 |
| 着席人数 | 参加ONで席に割り当てられている人 |
| 未着席人数 | 参加ONで席に割り当てられていない人 |
| 不参加人数 | 参加OFFの人。別に表示する |
| 空席数 | 割り当てのない席と、参加OFFの人が割り当てられている席 |

全体の氏名・属性表示をOFFにしても、人数の集計結果は変わらない。
未着席人数から該当者の一覧を開けるようにする。
重複配置などの問題がある場合は件数を表示し、対象を確認できるようにする。
見た目の警告だけでなく、どの卓・席に問題があるかを辿れるようにする。

### 6.9 元に戻す・やり直す

対象は卓の追加・移動・サイズ変更・削除、席数変更、参加者の割り当て・入れ替え・編集とする。
ドラッグ途中の座標や文字入力の途中経過を、1文字・1移動ごとに履歴にしない。
1回のドラッグや1項目の編集を、1回の操作で戻せる単位とする。
着席情報と参加者名簿を同時に変更する操作は、両方をまとめて戻す。
表示倍率・表示位置などの閲覧操作はデータ編集の履歴と区別する。
F5などのブラウザー再読み込み後も、操作履歴を保持して元に戻せるようにする。
現在のデータと履歴を対応付けてブラウザー内へ永続保存する。具体的な保存方式は実装側で検討する。

| 操作 | 履歴の扱い |
| --- | --- |
| F5・ブラウザーの再読み込み | 履歴を維持 |
| Excel・JSONから全体を復元 | 確認後に置き換え、履歴をリセット |
| 着席名簿だけ取り込む | 1操作として記録し、元に戻せる |
| 新規作成 | 確認後に初期化し、履歴をリセット |

履歴の上限件数は未決定。50件を確定値として扱わない。
ショートカットなどの細部は実装側で検討する。

### 6.10 ファイル操作・保存状態

ファイル操作は2.8のメニュー構成に集約する。
参加者画面と上部に同じファイル操作を重複配置しない。
全クリアを常時表示せず、ファイルメニューの「新規作成」へ整理する。
新規作成は確認後に机と参加者名簿を空にし、操作履歴をリセットする。
机・参加者名簿・履歴が消えることを確認画面に明記する。
「キャンセル」を初期選択とし、明示的に確定するまで初期化しない。
全体復元でも、現在のデータと履歴を置き換える確認画面を出す。
F5による再読み込みと、アプリのファイル読み込みを混同しない案内にする。

自動保存状態は「このブラウザーに自動保存済み」と表示する。
ブラウザー内の保存と、Excel・JSONへのファイル保存を区別する。
ブラウザーが違えば自動保存データも別であることが分かる案内を用意する。
保存状態は実際の保存処理の結果に基づいて表示し、失敗時に保存済みと表示しない。

### 6.11 実装候補の範囲と進め方

画面実装の候補範囲は、上部・中央・右側・下部の再配置、編集モード、卓・席編集、表示倍率、全体表示、検索、操作履歴、未着席者確認、状態表示とする。
ファイルメニューの整理では既存機能を接続し、未実装の新Excel形式を利用可能として表示しない。
Excelの2シート保存・全体復元・席番号インポートの実装は、画面再構成と分けて範囲を明示する。
既存の未コミット変更と保存データを保護し、必要なデータ互換性を確認する。

進め方の案は次の順とする。

1. 表示倍率・全体表示・元に戻す／やり直す
2. 右側の編集欄・モード切り替え・卓と席の操作
3. 検索・未着席一覧・人数と保存状態表示
4. 各段階でビルド・型チェック・ブラウザー操作を確認

この追記への承認は、コード変更や依存パッケージ追加の開始承認を意味しない。

### 6.12 実装側で検討する細部

基本の操作ルールはこの節より前に記載した決定事項を使う。
次の細部は実装時に検討し、操作結果や保存データに影響する選択は必要に応じて利用者へ説明する。

- 暫定採用した起動時の「着席編集＋全体表示」の使い勝手、編集欄を開く条件
- 狭い画面の切り替え幅、編集欄の幅と開閉の具体的な見せ方
- 属性見出しの変更画面、Excelの列との対応付け、保存場所
- 卓の追加時の初期席数・寸法、寸法変更の操作方法
- 複製時の重複しない卓名の生成方法、メニューからの貼り付け方法
- 同じ場所への連続貼り付けの操作感。重なり警告と自動位置調整は行わない
- 形状変更時の寸法の初期値と席の並びの具体的な計算
- 検索の一致ルール、候補の並び、未着席者を選んだ場合の表示
- 重複配置など不整合データがある場合の集計・対象表示
- 全体表示に含める範囲、用紙外の卓、表示倍率の上限・下限
- 既存の`scale`と新しい表示倍率の保存・復元方法
- 用紙向き変更の回転方向と、縦横を往復した場合の座標・席番号の整合
- 履歴の保存方式・容量管理・上限件数、入力確定の単位、復旧・保存失敗時の扱い
- 参加ON／OFF、表示設定、属性見出し変更を履歴に含める具体的な単位
- キーボード操作、入力中・編集欄操作中のショートカット抑止
- 表示倍率・表示位置・選択など、表示設定以外の閲覧状態を保存するか
- 参加ON／OFFの切り替えUIの配置と、複数参加者をまとめて変更する操作の必要性
- 用紙・文字サイズなど、新規作成時に机・名簿以外で初期化する項目
- 編集用の選択枠・強調表示をPDFなどの出力に含めない方法

### 6.13 画面実装後の確認項目

- 全体表示で用紙全体を見渡せる
- 表示倍率や表示位置の変更で机の座標・寸法・着席データが変わらない
- 狭い画面でも主要操作と会場図へアクセスできる
- 会場配置中に意図しない参加者の入れ替えが起きない
- 着席編集中に机の移動・サイズ変更が起きない
- 会場図と編集欄の卓・席選択が一致する
- 長い氏名や仮表示名を編集欄で全文確認できる
- 席の入れ替えの開始・完了・キャンセルが区別できる
- 卓名・参加者名の検索から目的の卓・席を確認できる
- 卓の追加後に追加した卓が見える
- 複製・削除・空席化で参加者が意図せず重複・消失しない
- 元に戻す／やり直すで配置・着席情報・参加者名簿の整合が保たれる
- 入力欄の操作で机の削除や複製が起きない
- 人数・未着席・問題件数と実際のデータが一致する
- 自動保存とファイル保存を利用者が区別できる
- 未実装のExcel復元機能を実装済みとして案内しない
- 保存・復元とPDF出力の既存機能を確認する
- 編集用の選択枠や一時的な強調が印刷出力へ混入しない
- F5で操作履歴が消えず、再読み込み後もデータと履歴の整合が保たれる
- 全体復元と新規作成は確認前にデータ・履歴を変更せず、確定後に履歴をリセットする
- 着席名簿だけの取り込みを元に戻せる
- Ctrl+Cだけでは卓が増えず、Ctrl+Vで参加者をコピーしない卓が追加される
- 貼り付け位置がマウス位置、会場図の外なら見える範囲の中央になる
- 卓の重なりに警告を出さず、自動で位置をずらさない
- 参加者一覧からの移動では元の席を空席にし、移動先の人を確認後に未着席へ戻す
- 卓の削除・空席化・席数削減で参加者名簿と参加ON／OFFが保持される
- 用紙の縦横変更で卓位置と長机の向きが回転し、着席情報を同じ卓・席番号に保持する
- 卓名の変更で着席情報が失われず、同名への変更を止める
- 形状の変更で席数・席番号・参加者の割り当てが失われない
- 氏名・属性の表示を切り替えてもデータと人数を変えず、PDFは表示設定に従う
- 参加OFFで氏名・属性を隠し、ONへ戻すと保持された席に再表示される
- 空席数に参加OFFの席を含め、参加ONの人数集計と不参加人数の表示を区別する
- 同姓同名と参加OFFの候補を属性・着席先・不参加表示で識別できる
